# Ponytail Help

Quick reference for Ponytail subskills. One-shot display when user asks for help.

## Intensity levels

| Level | What change |
|-------|-------------|
| **Lite** | Build what's asked, name the lazier alternative in one line. |
| **Full** | The ladder enforced: YAGNI → stdlib → native → one line → minimum. Default. |
| **Ultra** | YAGNI extremist. Deletion before addition. Challenges requirements before building. |

## Subskills (enable in Settings or chat +)

| Subskill | What it does |
|----------|--------------|
| **core** | Lazy mode itself. Simplest solution that works. |
| **review** | Over-engineering review: `L42: yagni: factory, one product. Inline.` |
| **gain** | Measured-impact scoreboard: less code, less cost, more speed. |
| **debt** | Harvest `ponytail:` comments into a debt ledger. |
| **audit** | Whole-repo over-engineering audit. |
| **help** | This card. |

Enable optional subskills via the Skills panel or chat **+** button.
