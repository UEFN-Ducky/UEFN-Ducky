# No official token — contributors cannot claim fees

There is **no official UEFN Ducky or DuckyOS cryptocurrency**.

The GitHub [Contributors](https://github.com/UEFN-Ducky/UEFN-Ducky/graphs/contributors) page is a commit list. It does **not** authorize anyone to:

- represent this organization
- launch a coin in this project's name
- claim pump.fun, bump.fun, or any other “creator” fees

This organization did not launch any token and will not claim creator rewards on unofficial coins.

Official support: [Patreon](https://www.patreon.com/UEFNDucky) · [uefnducky.org](https://uefnducky.org) · iliya@uefnducky.org
